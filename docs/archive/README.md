not need to read anything here. Moved or trimmed on 2026-09-23 (goal
`execution-guide-refocus-v1`); files moved whole are unchanged, so their
internal cross-references keep their original paths.

- `execution-pre-master.md` — the single-lead sections of the execution guide.
- `goal-pre-master.md` — the goal guide's rationale for the retired goal
  sections.
- `migration.md` — the one-time Elanc/Plans-to-Creme migration notes (was
  `docs/migration.md`).
- `acceptance/` — dated v0.1 acceptance records for clean-room, independent
  review, Linux, macOS, and self-hosting runs (were under `acceptance/`;
  `acceptance/client-discovery.md` stays live because a test reads it).
